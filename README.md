## 💼 Experience

### 🏢 FPT Software · Intern
**Jun 2026 – Aug 2026** · .NET 8 microservices · e-commerce and online-auction platform

<div align="justify">

A team project: an e-commerce and online-auction marketplace built as **.NET 8 microservices** (user, catalog, commerce, auction, fulfilment and notification services behind an API gateway).

</div>

> [!NOTE]
> **Key results:** **main developer** of the User Service · authentication service test coverage **0% → ~90%** · infrastructure layer **0% → 89%** · features delivered across **3 services** (User, Commerce, Auction)

**🔐 User Service** (main developer)
- **Authentication and authorisation:** JWT with a token blacklist, a privilege catalog with role–privilege management endpoints, admin user-management and audit-log APIs, and login rate limiting scoped to IP address and account.
- **Seller verification:** seller registration with KYC as a **state machine**, and Vietnamese citizen-ID (**CCCD**) identity verification with an admin review workflow and concurrency control.
- **Reputation system** rewritten in **five phases**: a scoring formula engine, one-time verification and seller-approval bonuses, a ratings pipeline with weekly aggregation, inactivity decay, and cross-service events that award or penalise reputation.
- **Service integration:** transactional **outbox pattern**, **RabbitMQ** consumers with dead-lettering, and a **gRPC** API that exposes user and reputation snapshots to other services.
- **Testing:** unit tests that raised coverage (authentication service **0% → ~90%**, infrastructure layer **0% → 89%**) and integration tests against a real SQL Server to prove idempotency.

**🛒 Commerce Service**
- **Cart APIs and price calculation**, **checkout-to-order** creation with order-management APIs and RBAC, inventory reservation through the outbox pattern and gRPC, and an **idempotent payment-callback handler** with cancel and refund.

**🔨 Auction Service**
- **Auction lifecycle** API and state machine, the **place-bid API with optimistic concurrency**, **real-time bidding with SignalR**, payment deadlines and payment synchronisation, and a reputation-based bidding eligibility check with caching and a resilience fallback.

**🤝 Way of working:** feature branches and **GitLab merge requests** into a shared `develop` branch, API contracts agreed in shared design documents, services run together locally with **Docker Compose**.

**Tech:** ASP.NET Core 8 · EF Core 8 · SQL Server · Redis · RabbitMQ (MassTransit) · gRPC · SignalR · Docker · xUnit · SonarQube · GitLab

## 🚀 Featured Project: VQT Japanese Food

<div align="justify">

A full-stack e-commerce web application for a Japanese food store in Vietnam, rebuilt from a classic ASP.NET MVC site into a **React single-page app** on an **ASP.NET Core 9 Web API** (personal project, 2026).

</div>

> [!TIP]
> **Explore it:** [Source code](https://github.com/jasonvuong20032/vqt-japanese-food) · [How it works and how to run it](projects/vqt-japanese-food.md) · [ERD](https://github.com/jasonvuong20032/vqt-japanese-food/blob/main/docs/erd.md) · [Sequence diagrams](https://github.com/jasonvuong20032/vqt-japanese-food/blob/main/docs/sequence-diagrams.md) · [Use cases](https://github.com/jasonvuong20032/vqt-japanese-food/blob/main/docs/use-cases.md)

- **Layered architecture** (controllers → service layer → EF Core → SQL Server) with a **24-table database**: order lines that snapshot prices, order status history, and translation tables for five languages.
- **Secure checkout:** prices and totals are recalculated on the server, and stock is reserved with conditional updates inside a transaction so the last item can never be sold twice.
- **Authentication** with JWT in HttpOnly cookies, rotating refresh tokens with reuse detection, role-based access for staff and administrators, and rate limiting on sign-in and checkout.
- **Back office** with a revenue dashboard, an order workflow that emails customers in their own language, dish and photo management, coupons, review moderation and staff management.
- **5 languages** (Vietnamese, English, Japanese, Korean, French) and **4 colour themes**.
- **132 automated tests** (84 backend with xUnit, 48 frontend with Vitest), plus documentation: ERD, sequence diagrams and use case specifications.

**Tech:** C# · .NET 9 · ASP.NET Core Web API · EF Core 9 · SQL Server · React 19 · TypeScript · Vite · Tailwind CSS 4 · TanStack Query · i18next · xUnit · Vitest
